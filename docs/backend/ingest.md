# ingest.md

後端取得「一個可以安全走訪的根目錄」的規則。目前只有本機路徑這條路；zip 是階段 3。

各階段職責見 CLAUDE.md › 架構 › ingest。

---

## 這一層在防什麼

使用者貼一個路徑字串，後端就會用它去讀檔案。沒有閘控的話，貼 `/etc`、`~/.ssh`、`/` 都會照讀，等於任何打得到 API 的人都能瀏覽整台機器。

所以本機路徑模式**必須由允許清單閘控**（CLAUDE.md › 安全性約束）。這是這一層存在的理由。

---

## 允許清單

| 項目 | 值 |
|---|---|
| 環境變數 | `CODEGRAPH_ALLOWED_ROOTS` |
| 分隔符 | `os.pathsep`（Linux 是 `:`） |
| 空白項 | 忽略 |
| **未設定或為空** | **拒絕所有路徑** |

未設定時是「什麼都不准」而不是「沒有限制」—— 忘記設環境變數的後果必須是功能不能用，不能是整台機器開放。出錯要往關閉的方向倒。

---

## 檢查規則

天真的字串開頭比對有三種繞法，全部要擋掉：

| 使用者給的路徑 | 為什麼騙得過字串比對 | 怎麼擋 |
|---|---|---|
| `/allowed/../../etc` | 開頭確實是清單上的路徑 | 先 `Path.resolve()` 把 `..` 算掉再比對 |
| `/allowed_other` | 開頭字串對得上 `/allowed` | 用 `is_relative_to()` 按目錄層級比對，不用 `startswith` |
| `/allowed/link` 指向 `/etc` | 字串完全合法，實際指向別處 | `resolve()` 會把 symlink 跟到底，比對的是最終位置 |

清單本身也 `resolve()` 後才比對，否則清單裡寫了 symlink 就會對不上。

### 檢查順序：先清單，後存在

**先判斷在不在清單內，通過了才檢查存不存在。**

反過來的話，錯誤訊息會變成一個探測工具：對清單外的路徑回「不存在」或「不是目錄」，等於告訴對方那個路徑存不存在。清單外的一律只回同一種錯誤。

## 介面

```python
def allowed_roots_from_env(env: Mapping[str, str] | None = None) -> list[Path]: ...
def from_local_path(raw_path: str, allowed_roots: Sequence[Path]) -> Path: ...
```

清單**以參數傳入**，核心函式不自己讀環境變數。讀環境變數是薄薄一層，由呼叫端組合。

| 好處 | 說明 |
|---|---|
| 可測 | 測試直接餵一份假清單，不必 monkeypatch 環境變數（那種測試容易互相干擾） |
| 無全域可變狀態 | 與 CLAUDE.md 對語言 registry 的要求一致：以參數傳入，不做成全域狀態 |

函式命名避開 `resolve` —— 那個字在本專案已是管線某一段的名字（名字 → 節點）。zip 那條路日後叫 `from_zip()`，兩者對稱。

---

## 錯誤

以例外 `IngestError` 表達，不回錯誤碼：ingest 不認識 HTTP，狀態碼由 API 層決定。

**例外訊息含絕對路徑，不可原樣回傳給前端。** 「`/etc` 不在允許清單 `/home/user/project` 內」這種訊息等於把伺服器的目錄結構與清單內容送出去。詳細訊息只進日誌，對外只說路徑不被允許。

## 不在這一層做的事

| 事情 | 在哪做 | 為什麼不在這 |
|---|---|---|
| 跳過 `.git` / `node_modules` / `__pycache__` | scan | 那是雜訊過濾，與安全無關。混在一起之後沒人分得出哪條規則是為了擋攻擊 |
| 只挑 `.py` 來解析 | parse | 那是能力邊界。非 Python 檔案仍要有 `file` 節點 |
| 走訪目錄、看檔案內容 | scan | ingest 只交出一個根目錄 |
| 「往下鑽一層找真正的根」 | zip 那條路（階段 3） | 本機路徑給的就是根，沒有多包一層的問題 |

## 未定之處

| 項目 | 缺什麼 |
|---|---|
| 清單內部的 symlink | 這一層只檢查**入口那一個路徑**。清單內的資料夾裡若有 symlink 指向 `/etc`，走訪時仍會逃出去。scan（plan 1.4）要定「是否跟隨 symlink」，預設不跟隨較安全 |
| 清單的來源 | 目前只有環境變數。日後若要支援設定檔，`from_local_path()` 不用改，只多一個組清單的函式 |
